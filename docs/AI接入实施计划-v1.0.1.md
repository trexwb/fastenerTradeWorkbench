# DeepSeek AI 接入实施计划（v1.0.1）

依据《AI接入方案-DeepSeek》，本次完成浏览器形态的 Phase 0、Phase A 与 Phase B MVP；Tauri 桌面打包属于独立交付形态，未纳入本次零依赖 HTML 版本。

| 阶段 | 内容 | 状态 |
|---|---|---|
| Phase 0 | 本机代理、会话访问码、请求限制、120 秒超时、取消、默认脱敏及本地金额聚合 | 已完成 |
| Phase A | 健康探测、AI 抽屉、确认发送、SSE 流式显示、离线降级 | 已完成 |
| Phase B | 7 个快捷指令、视图上下文、关键词数据快照、最近 50 条本机历史、极简安全 Markdown | 已完成 |
| Phase C | Tauri `Channel` / Rust 进程内密钥 / 安装包 | 后续可选 |
| Phase D | 订单与客户实体跳转、更多 Markdown、体验细化 | 后续可选 |

## 验收步骤

1. 直接双击 `index.html`：核心业务可用，AI 图标显示未连接但不会报错。
2. 运行 `DEEPSEEK_API_KEY=sk-你的密钥 node tools/ai-proxy.js`。
3. 打开 AI 助手，粘贴终端给出的会话访问码；状态显示“已连接”。
4. 点击“经营总结”并审阅快照，确认后验证流式回复和本机历史。
5. 停止代理后刷新工作台：AI 恢复离线提示，订单、结算等功能保持可用。

## 安全边界

- API Key 只来自代理进程环境变量；前端不接收、不保存 Key。
- 会话访问码由代理生成，仅由用户复制到当前页面内存，不写入 IndexedDB 或 localStorage。
- 本次快照默认排除联系人电话、地址、税号、银行账户与完整备注。
- 金额、利润、应收应付与排行先由本地只读聚合器计算，模型只解释与生成建议。
