# Phase 1 详细设计 · 紧固件贸易工作台

> 版本：v1.0（2026-08-20）
> 依据：`docs/开发计划-2026-08-20.md`（v2.0）
> 范围：Phase 1 全部 8 项功能（#1-#8），内嵌 P0「单笔利润即时核算」（#17）
> 定位：离线单干版超简单 CRM + 个人贸易工作台

## 0. 范围与依赖

| # | 功能 | 依赖现有模块 | 新增数据 |

| 6 | 一键复制订单 | 采购订单(自身) | 无新表 |

**范围说明**：`今日待办清单`（#9）在 v2.0 计划中位于 Phase 2 表，但其 P0 优先级允许在 Phase 1 数据（跟进记录、报价单）就绪后提前实施，详细设计放 Phase 2 章节，不纳入本文。

**单位约定**：报价单与订单保持一致，`qty` 单位均为**千支**（可小数，如 5 = 5 千支），金额单位为元。开发计划示例中的 `qty:5000` 视为笔误，设计按千支执行。

## 2. 数据层设计（store.js）

### 2.1 `ensureDBFields()` 新增迁移（幂等，不破坏已有数据）

```js
if(!DB.quotes) DB.quotes=[];
if(!DB.followUps) DB.followUps=[];
DB.units.forEach(u=>{ if(!u.tags) u.tags=[]; });   // 分级标签
```

### 2.2 `DB.quotes`（沿用开发计划，补充字段说明）

```js
{
  id:'QT260820-001',          // QT + 年月日 + 3位序号，独立 quoteSeq 生成
  buyerId:'U1',               // 关联 units
  date:'2026-08-20',
  items:[{
    sku:'', type:'螺栓', standard:'GB/T', diameter:'M8',
    hardness:'8.8', surface:'本色', material:'304',
    qty:5,                    // 千支
    costPrice:0.95,           // 成本价（自动匹配或手填）
    salePrice:1.20,           // 售价（利润率算或手填）
    profitRate:26.3,          // 利润率%（售价/成本反算，保留1位）
    profit:1.25               // 单行利润 = (sale-cost)*qty
  }],
  totalCost:4750, totalSale:6000, totalProfit:1250,
  avgRate:20.8,               // 加权平均利润率
  status:'待确认',            // 待确认/已确认/已转单/已废弃
  orderId:'',                 // 转单后回写
  remark:'',
  createdAt:'2026-08-20'
}
```

- 报价编号：`DB.quoteSeq` 独立自增，逻辑同 `orderSeq`（防删除后重号）。
- 报价单创建即算总账；**编辑仅限「待确认」状态**。

### 2.3 `DB.followUps`（沿用开发计划结构，无改动）

```js
{ id:'FU1', unitId:'U1', date:'2026-08-20', method:'电话',
  content:'...', nextDate:'2026-08-25', orderId:'', createdAt:'2026-08-20' }
```

### 2.4 `units.tags`（新增）

```js
{ ..., rating:'主力', tags:['长期合作','主推'] }  // 字符串数组，最多5个
```

## 3. 功能详细设计

### 3.1 快速报价单（#1，P0）

**入口**：侧边栏「报价管理」→ 列表页右上「新建报价」；或快捷键 `⌥+⇧+Q`。

**列表页（viewQuotes）**：
- 顶部：搜索框（客户名/报价单号）+ 状态 Tab（全部/待确认/已确认/已转单/已废弃）
- 表格列：报价单号 | 客户 | 日期 | 总售价 | 总利润 | 利润率 | 状态 | 操作
- 操作按钮：详情 / 编辑(待确认) / 转订单(待确认·已确认) / 复制 / 废弃
- 分页沿用现有 `PAGE_SIZE` 机制

**新建/编辑报价流程（viewQuoteEdit）**：

```
① 选客户（必填，roles 含客户/采购商的 units，含搜索）
   ↓
② 添加产品行：复用订单现有 SKU 选择器（属性管理数据源），
   支持手动输入规格
   ↓
③ 成本价自动匹配（优先级）：
   a. 签约管理 DB.prices 中 规格匹配 的成本价
   b. 历史采购：orders 中同 SKU 最近一条 purchasePrice
   c. 都没有 → 留空手动填
   ↓
④ 每行二选一联动（实时计算，内嵌 P0 利润核算）：
   - 填利润率% → salePrice = cost × (1+rate)
   - 填售价 → profitRate = (sale-cost)/cost
   行内实时显示：利润、利润率（利润率<10% 标红提示）
   ↓
⑤ 汇总区：总成本 / 总售价 / 总利润 / 加权平均利润率
   ↓
⑥ 备注（可选）→ 保存
```

**交互细节**：
- 行内编辑直接改 input，不弹窗；规格列点击可展开选择器
- 同 SKU+规格 重复行：检测并 toast 提示合并（复用订单逻辑）
- 报价单支持「一键复用历史」（见 3.5），选客户后自动提示最近报价

**详情页（viewQuoteDetail）**：报价单头 + 明细表 + 汇总 + 备注，按钮：转订单 / 复制 / 导出 / 打印。

**导出/打印**：复用现有导出机制输出 Excel 报价单；打印走浏览器打印友好样式（`@media print`）。

### 3.2 报价转订单（#2，P0）

**入口**：报价列表/详情「转订单」按钮。

**前置校验**：仅 `待确认` / `已确认` 可转；已转单提示跳转关联订单；已废弃不可转。

**流转逻辑（预填式，改动最小）**：

```
点击「转订单」
  → 全局写入 _quoteTransfer = {quoteId, buyerId, buyerContact, items, remark}
  → 跳转订单编辑页（_fMode='new'）
  → 订单编辑页加载时检测 _quoteTransfer：
       buyerId / 联系人 / items 深拷贝预填
       items 映射：{sku,type,standard,diameter,hardness,surface,material,
                    qty,salePrice,costPrice(带过去供后续利润核算), remark 附报价单号}
       remark 前缀「来自报价 QT260820-001」
  → 用户补充交货期 / 状态后保存（走现有 saveOrder）
  → 保存成功后回写：
       quote.status='已转单'; quote.orderId=新订单ID;
       _quoteTransfer=null（防重复回写）
```

**字段映射**：报价 item → 订单 item 全字段对齐，`quotePrice` 取报价 salePrice，供订单页报价比对功能沿用。

**失败兜底**：订单保存校验失败（如缺交货期）→ 保留预填内容在编辑页，报价单状态不变，用户可继续编辑或取消返回。

### 3.3 客户跟进记录（#3）

**入口**：
- 关联单位列表每行新增「跟进」按钮（打开该单位的跟进抽屉）
- 关联单位详情页新增「跟进记录」区块

**列表呈现（时间线倒序）**：
```
[2026-08-20 电话] 客户确认M8螺栓规格…    下次跟进: 08-25  [编辑][删除]
[2026-08-12 微信] 发送新样品图片…         下次跟进: -       [编辑][删除]
```

**新增/编辑表单（弹窗）**：
- 联系日期（默认今天）
- 沟通方式：电话 / 微信 / 拜访 / 邮件（select）
- 沟通内容（textarea，必填）
- 下次跟进日期（date，可空）
- 关联订单（可选，搜索选择，方便追溯）

**单位详情头部增强**：显示「最近跟进: 3 天前 / 下次: 08-25」，超期标黄。

**数据流**：增删改查 `DB.followUps`，按 `unitId` 过滤，`nextDate` 供 Phase 2 今日待办聚合。

### 3.4 客户分级与标签（#4）

**分级（已有 rating，低成本增强）**：
- 单位编辑表单保留现有 主力/备选/新客 下拉
- 列表 tab 筛选保留；详情页顶部显示分级徽章（沿用现有 tag 样式）

**标签（新增）**：
- 单位编辑表单增加「标签」输入：逗号分隔，转数组存储（最多 5 个）
- 列表新增「标签」列：渲染为多个小徽章（`tag` 样式），支持点击按标签筛选
- 单位详情页显示标签

**数据流**：读写 `units.tags`，空数组不显示徽章；筛选逻辑沿用现有 rating filter 模式扩展。

### 3.5 常用模板与历史复用（#5）

**场景 A：同客户历史报价复用（新建报价时）**
- 选完客户后，若该客户存在历史报价，弹出提示条：「有 3 份历史报价，点击复用」
- 复用弹窗：列出该客户历史报价（日期/单号/金额），选中后 **items + remark 深拷贝载入编辑区**，用户可改数量/价格后另存新报价
- 相当于报价单的「复制」能力，跨客户不可复用（价格不串）

**场景 B：按客户查历史报价**
- 报价列表页搜索框输入客户名即可过滤；列表页提供「按客户分组」折叠视图

**场景 C：产品维度价格记忆**
- 报价行内成本价自动匹配（3.1③）已覆盖「同产品上次价格」诉求：优先签约价，其次该 SKU 最近订单采购价

### 3.6 一键复制订单（#6）

**入口**：订单列表每行「复制」按钮 + 订单详情页「复制订单」按钮。

**逻辑**：
```
点击「复制」
  → _fMode='new'; _fOrderId=null
  → _fItems = 原订单 items 深拷贝（保留 qty/salePrice/sku/规格；
      清空 options 分配，因为新订单需要重新分配供应商）
  → 预填 buyerId / 联系人 / 项目 / 备注（备注附「复制自 PO260805-001」）
  → status 置为草稿态（沿用订单默认）
  → 跳转订单编辑页，提示「已复制，修改后保存为新订单」
```

**防误**：复制不改变原订单任何字段；新订单保存时走独立序号生成，不重号。

### 3.7 快捷通讯录（#7）

**入口**：顶部工具栏新增电话图标按钮（或 `⌥+⇧+C`，C=Contact）；不做独立导航，避免侧边栏臃肿。

**弹窗交互**：
```
┌ 快捷通讯录 ────────────────────────┐
│ [全部|客户|供应商]  [搜索姓名/公司🔍] │
│ ───────────────────────────────── │
│ 张三  华东机械  客户  138****1234 [复制][拨号] │
│ 李四  顺达紧固件厂 供应商 139****5678 [复制][拨号] │
└───────────────────────────────────┘
```

- 数据源：`DB.units[].contacts`（含 name/phone/wechat）
- 角色筛选：按 unit.roles 判断（客户=roles 含采购商/客户；供应商=roles 含供应商）
- 复制：`navigator.clipboard.writeText(phone)`，toast 提示
- 拨号：`tel:` 链接（macOS 触发 FaceTime/电话 App）
- 微信：点击复制微信号

**搜索**：输入即过滤（姓名/公司名/电话子串）。

### 3.8 报价历史比价（#8）

**入口**：
- 属性管理：规格行新增「比价」按钮
- 报价编辑页：成本价输入框旁「查底价」小图标
- 签约管理：价格行「比价」按钮

**聚合逻辑**：同规格（type+standard+diameter+hardness+surface+material 全匹配，材料为空时放宽）合并三源：

| 来源 | 数据 | 取价字段 |
|---|---|---|
| 签约管理 | DB.prices | 单价 |
| 采购订单 | DB.orders[].items | purchasePrice |
| 报价单 | DB.quotes[].items | costPrice |

**弹窗表格**（按单价升序，一眼看穿底价）：
```
规格: 螺栓 GB/T M8 8.8 本色 304
供应商       单价(元/千支)  日期        来源
顺达紧固件厂  0.88          2026-07-28  采购订单
精工不锈钢    0.95          2026-08-15  签约管理
华强五金      0.98          2026-08-10  报价单成本
```

**细节**：供应商名称从 units 解析；无供应商的报价来源显示「历史报价」；点击行可复制单价。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 转单预填字段与订单校验冲突 | 转单只预填不绕过校验，保存失败保留编辑态，报价状态不变 |
| 报价/订单 qty 单位歧义 | 统一千支，UI 明确标注「千支」 |
| 比价三源数据缺失规格 | 匹配放宽（材料可空），无结果显示「暂无比价数据」 |
| 标签筛选与现有筛选冲突 | 筛选为「且」关系：评级 Tab + 标签 chip 可叠加 |
| 编辑已转单报价导致数据不一致 | 编辑仅限「待确认」，已转单/已确认只读 |
*（内容由AI生成，仅供参考）*
