# AI 本地代理

浏览器直接双击 `index.html` 时，AI 功能需要此可选代理解决跨域问题。核心业务不依赖代理，离线仍可正常使用。

```bash
DEEPSEEK_API_KEY=sk-你的密钥 node tools/ai-proxy.js
```

启动后，终端会显示一次性的“会话访问码”。在工作台的 AI 助手设置中输入该访问码；它只保存在当前页面内存，刷新后需重新输入。API Key 不会写入浏览器、项目文件或命令行参数。

代理只监听 `127.0.0.1:7842`，仅使用 Node.js 内置模块。按 `Ctrl+C` 停止后，内存中的 Key 与访问码立即清除。
