# AI 助手

**可选增强模块**：未配置 API Key 或无网络时，全部核心业务功能照常可用。

启用后可用自然语言做经营分析、起草数据操作、查询系统帮助、检索本地知识库。

## 一、运行形态与 Key 存储

| 形态 | 识别条件 | API Key 存储 |
|------|---------|-------------|
| 桌面版（Tauri） | 检测到 `window.__TAURI__` | 应用数据目录 `deepseek_token` 文件（不进 localStorage） |
| 浏览器版（含 file://） | 其他 | localStorage `wb_fastener_ai_key`（仅本机可见） |

入口：顶栏闪电图标 · 快捷键 `⌥ + I` · 命令面板（`⌘K`）无结果回车 / `?` 前缀 / `Tab`

状态指示：绿色「● 直连就绪 / 桌面就绪」= 已配置；黄色「● 未设置 API_KEY」= 需先配置。

| 本地 oMLX | `http://127.0.0.1:8000/v1` | `qwen2.5` |

- 预置推荐模型：`deepseek-v4-flash`（默认）/ `deepseek-v4-pro` / `gpt-4o-mini` / `gpt-4o` / `qwen-plus` / `glm-4-flash` / `llama3` / `qwen2.5`

- **Ollama**：Key 可留空（自动发占位 `Bearer ollama`）；**oMLX**：需填写与自身配置一致的真实 Key

## 三、两种模式

| 模式 | 说明 |
|------|------|
| 只读分析 | 基于**脱敏业务快照**回答经营总结、催款建议、比价、客户分级、话术生成、利润分析 |
| 工具调用（写入） | AI 起草数据操作（单位/报价/订单 CRUD、寻货、状态流转、导航、Excel 导出），**逐条经确认弹窗后执行** |

## 四、Function Calling（47 个工具）

| 类别 | 数量 | 是否确认 | 审计 | 回滚 |
|------|------|:---:|:---:|:---:|
| 查询类 `query_*` | 7 | 自动执行 | 不记 | — |
| 功能层 `navigate_view` / `open_*_drawer` / `open_*_form` | — | 自动执行 | 不记 | — |

## 五、安全与能力边界

- AI **只产出参数**，执行复用业务校验与 `saveDB()` 链路
- 确认弹窗不可跳过，拒绝零写入
- 删除走**软删除**进回收站；AI 无彻底删除能力
- **AI 与回收站完全隔离**（不可查看 / 恢复 / 彻底删除）
- 敏感字段（电话 / 地址 / 税号 / 银行账户）AI 不收集，由用户在确认弹窗补全
- 并发保护：确认弹窗生成指纹，执行前比对，数据被改动则拒绝
- 金额、利润、余额、排名一律以本地快照为准，模型不得替代确定性计算

## 六、对话附件（v1.0.40 / v1.0.41）

- 支持 txt / md / markdown / log / csv / xls / xlsx / docx / pdf
- 单文件 ≤ 20MB，单条消息最多 6 个；PDF ≤ 200 页；Excel ≤ 20 sheet
- 添加方式：附件按钮（可多选）、拖拽到助手窗口、**（仅桌面版）正文写文件路径**（`/绝对路径`、`C:\盘符`、`~/家目录`）
- **本地直读**：不上传服务器、不产生临时文件；GBK 自动识别；扫描型 PDF（无文字层）不支持
- 注入预算：当轮单附件 30000 字 / 单轮 60000 字；历史附件 2000 字/附件

## 七、本地知识库 RAG

- 绑定本地目录（md / txt / pdf / docx），自动增量索引 + 定时静默更新
- BM25 检索，相关度阈值过滤后取 Top-N（默认 4，可选 3/4/5）
- 回答带【依据：文件名】，可点击查看原文
- 索引存独立库 `wb_fastener_kb`，与业务库隔离
- **全程不联网、不消耗 token**

> 与「对话附件」的区别：知识库是目录级长期资料库（检索注入）；附件是单条消息级全文注入（临时读一份文件）。两者独立，可同时使用。

## 八、审计与回滚

- 每轮 AI 写入后消息下方有「**撤销本轮改动**」按钮，按 `aiOps` 反向回滚
- 也可在 [数据管理 → 操作历史](数据管理.md#五操作历史) 单条或整批回滚
- 刷新不失效，不误伤手动操作

## 九、常用提问

冷启动（无对话历史）显示单行横向滚动 chips：经营总结 / 催款建议 / 比价分析 / 客户分析 / 话术生成 / 利润分析 / 任意提问。有对话记录后隐藏，清空对话后恢复。
