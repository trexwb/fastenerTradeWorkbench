# 快速开始

## 1. 打开工作台

**浏览器版（推荐）**：直接双击 `dist/index.html`（构建产物）。无需安装任何软件、无需联网、无需本地服务器。推荐 Chrome / Edge。

首次打开会看到预置的示例数据（关联单位、报价、订单），可随时在 [数据管理](数据管理.md) 中清空。

**开发调试**（需 Node.js）：

```bash
npm install
npm run dev        # Vite 开发服务器 http://localhost:1421
npm run vite:build # 构建零依赖产物到 dist/
```

**桌面版**（Tauri）：`npm run tauri:build` 打包为 `.app` / `.dmg` / 安装包，额外支持自动更新、正文写路径直读、API Key 存应用数据目录。

## 3. 推荐首次操作顺序

1. **关联单位** — 录入采购商与供应商（可先做批量导入）
2. **属性管理** — 确认六维枚举值（类型/标准/直径/硬度/表面处理/材质）
3. **BOM 管理** — 建立 SKU 物料清单（可批量导入）
4. **签约报价** — 录入供应商 × SKU 的报价
5. **采购订单** — 新建订单 → 添加产品 → 寻货分配 → 流转状态
6. **对账结算 / 发票管理** — 订单进入「签约完成」及之后自动参与聚合
7. **数据管理** — 绑定本地 JSON 文件做持久备份（强烈推荐）

## 4. 必知的三条规则

- **搜索框回车才搜索**：不使用实时搜索，避免中文输入法候选干扰
- **AI 写入需逐条确认**：AI 只产出提案，不合你确认不会改数据
- **删除是软删除**：所有删除进回收站，90 天内可恢复

## 5. macOS 桌面版「已损坏」处理

macOS 桌面版为 ad-hoc 签名（未公证），下载后会被叠加隔离标记，首次打开被拦截并提示「已损坏，无法打开」——**并非文件真的损坏**。在「终端」执行：

```bash
xattr -dr com.apple.quarantine "/Applications/FastenerTradeWorkbench.app"
```

提示 `Operation not permitted` 时加 `sudo `；应用不在「应用程序」目录时替换为实际路径；重新下载安装包后需再执行一次。
