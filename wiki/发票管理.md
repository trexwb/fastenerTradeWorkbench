# 发票管理

开票 / 收票记录**由结算同步生成**（`syncInvoices()` 从结算聚合），可在列表中编辑金额、日期、备注。

## Tab 结构

| Tab | 路由 key | 说明 |
|-----|---------|------|
| 开票记录 | `inv-issue` | 我方开给采购商 |
| 收票记录 | `inv-receive` | 我方从供应商收取 |

每个 Tab 内再分「未结 / 已结」子 Tab（`⌥ + ←` / `⌥ + →` 切换）。

## 字段说明

| 字段 | 说明 |
|------|------|
| 单位 | 采购商（开票）/ 供应商（收票） |
| 关联结算 | 来源结算记录 ID |
| 发票号 | 手工填写 |
| 金额 | 默认同步结算金额，可编辑 |
| 开票 / 收票日期 | 可编辑 |
| 状态 | 未开 / 已开（收票：未收 / 已收） |
| 备注 | 补充说明 |

## 编辑发票

`openInvEdit(invId)` 抽屉中修改 → 保存即时生效。

## 孤儿发票标记（v1.0.56 起）

删除结算记录时若未勾选级联删除，关联发票的 `settleId` 会悬空。系统通过 `syncInvoices` 自动标记 `orphan`，列表行显示「**来源已删**」标签；悬空消除（重新关联或恢复结算）后标签自动摘除。

## 数据结构

```javascript
DB.invoices = [{
  id:'INV1', type:'issue',        // issue 开票 / receive 收票
  unitId:'U101', settleId:'S1',
  amount:12000, date:'2026-08-25',
  invoiceNo:'0441xxxx', status:'已开',
  remark:''
}];
```

## 常见问题

**Q：发票能手工新建吗？**
发票由结算同步生成，不提供独立新建入口。请先在 [对账结算](对账结算.md) 中建立结算记录。

**Q：显示「来源已删」怎么办？**
关联的结算记录已被删除。可到 [回收站](数据管理.md#回收站) 恢复该结算，或彻底删除这条孤儿发票。

**Q：金额与结算不一致？**
发票金额允许手工调整（例如部分开票）。如需对齐，编辑发票改回结算金额即可。
