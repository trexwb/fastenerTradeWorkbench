# 签约报价

供应商 × BOM SKU × 单价的报价记录库，是寻货时「价格库匹配」的数据来源。

## 字段说明

| 字段 | 说明 | 必填 |
|------|------|:---:|
| 供应商 | 从关联单位选择（角色含供应商） | ✅ |
| SKU | 关联 BOM 的 SKU（选中 BOM 仅回填此项） | 否 |
| 六维属性 | 类型/标准/直径/硬度/表面处理/材质 | 否 |
| 规格 | 规格描述 | 否 |
| 单价 | 元/千支 | ✅ |
| 有效期 | 报价生效日期 | 否 |
| 联系人 | 供应商联系人 | 否 |
| 备注 | 补充说明 | 否 |

## 新增报价

工具栏为**分体下拉**：「新增报价」主按钮 + 更多操作下拉（含「批量导入」）。

防重复规则：同一「供应商 + SKU + 规格 + 属性」组合不允许重复录入。

**自动入库**：在采购订单中手动录入供应商时，系统会自动把该报价写入价格库，无需重复维护。

## 批量粘贴导入

- 入口：工具栏「更多操作 → 批量导入」
- 复制 Excel 区域 → 粘贴到文本框 → 解析预览 → 提交
- 按「供应商 + SKU + 规格 + 属性」去重，重复行跳过
- 支持二次粘贴累加

## 筛选与搜索

`filterPrices()` 渲染列表，支持：

- 按供应商筛选（多选 checkbox）
- 按 SKU / 规格关键词搜索
- 按有效期排序

## 编辑与删除

- 编辑：抽屉内修改字段，保存即时生效
- 删除：软删除进 [回收站](数据管理.md#回收站)，可恢复

## 与寻货的关系

寻货弹窗的「价格库匹配」按以下规则命中（v1.0.54 起）：

1. 订单行与报价**都有 SKU** → 必须**完全一致**才命中
2. 报价**无 SKU** → 仅当订单行有六维属性可核验且一致时兜底显示
3. 订单行**无 SKU** → 沿用旧的属性匹配

> 这样设计是为了避免「订单行属性大多留空 → 全量报价命中」的噪音。
