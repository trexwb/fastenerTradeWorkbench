# 采购订单

工作台核心模块，包含从订单创建到完成的完整生命周期。

视图三态：

| 状态变量 | 渲染函数 | 页面 |
|---------|---------|------|
| `curOrder` | `viewOrderEdit()` | 编辑 / 新建（表单 + 产品明细） |
| `curOrderView` | `viewOrderDetail()` | 详情只读（含寻货入口） |
| 两者皆空 | `viewOrders()` | 订单列表 |

## 一、创建订单

| 字段 | 说明 | 必填 |
|------|------|:---:|
| 采购商 | 搜索选择已有采购商 | ✅ |
| 对接联系人 | 选择采购商后自动带出 | 否 |
| 项目背景 | 项目描述或用途 | 否 |
| 期望交货期 | 日期选择 | ✅ |
| 订单状态 | 默认「待确认」 | 否 |
| 订单备注 | 补充信息 | 否 |

订单号自动生成：`PO + YYMMDD + 序号`（如 `PO260811-001`），序号由独立的 `orderSeq` 维护，删除订单不会导致序号重复。

## 二、产品明细

可手动填写，也可从 BOM 选择（**仅回填 SKU**）。

| 字段 | 必填 |
|------|:---:|
| SKU / 名称 / 规格 | 视寻货校验而定 |
| 类型 / 标准 / 表面处理 | 否 |
| 直径 / 材质 / 硬度 | 是 |
| 数量（千支） | 是 |
| 销售单价（元/千支） | 是 |
| 用途 / 备注 | 否 |

## 三、状态机（九态）

```
待确认 → 寻货中 → 报价中 → 签约完成 → 送货中 → 完成
                       ↘ 未成交（可恢复回报价中）
        非终态 ↘ 异常 / 取消（终态）
        完成   ↘ 送货中 / 异常
```

| 状态 | 含义 |
|------|------|
| 待确认 | 订单刚创建，等待确认需求 |
| 寻货中 | 正在匹配供应商、分配采购量 |
| 报价中 | 寻货完成，与采购商报价中 |
| 未成交 | 报价后未签约，可恢复回「报价中」 |
| 签约完成 | 合同已签，执行中 |
| 送货中 | 已发货交付 |
| 完成 | 全部交付完成 |
| 异常 | 出现问题，需关注 |
| 取消 | 订单已取消 |

流转校验收口于 `validators.canFlowOrderStatus(from,to)`，视图按钮与 AI 工具 `flow_order_status` 共用。

> v1.0 迁移：旧状态「待签约」已统一迁移为「报价中」。

**结算口径提示（v1.0.56 起）**：订单从「签约完成 / 送货中 / 完成」转出到非聚合状态、且存在关联结算记录时，会弹确认窗提示影响金额（记录保留，恢复状态后重新计入）。

## 四、送货信息与收货管理

> **权限白名单（v1.0.38 起）**：仅订单状态为「送货中」时可编辑，其它任何状态一律只读（隐藏编辑入口并显示 🔒）。

链路：**供应商 → 我方收货验货 → 采购商**。导出「送货结算单」时包含：快递至采购商的地址/单号/时间，及各供应商的邮寄信息。

## 五、Excel 导出

按订单状态分发模板（`exportOrder(orderId)`）：

| 状态 | 导出内容 |
|------|---------|
| 待确认 | **产品确认单**（含勾选确认列，供采购商回填） |
| 寻货中 | **寻源进度单**（产品进度 + 供应商报价对比 + 决策提示） |
| 报价中 / 未成交 | **报价中报价单**（产品主行 + 供应商报价子行，「供应数量提醒」区红色标出未满足需求的产品） |
| 签约完成 | **签约完成结算单**（采购商应收 + 供应商应付，含已收/已付/未结与红色提醒） |
| 送货中 / 完成 | **送货结算单**（结算明细 + 送货信息 + 供应商邮寄信息） |
| 其余状态 | 通用采购订单 |

## 六、批量导入

三处入口，统一「复制 Excel → 粘贴 → 解析预览 → 提交」交互：

| 入口 | 规则 |
|------|------|
| 采购订单（列表页「新建」下拉） | 相邻且「采购商 + 项目 + 交货日期」相同的行**自动合并为一单**；采购商不存在自动新建；日期多格式归一化；状态一律「待确认」 |
| 订单产品明细（编辑页） | 按 SKU 去重 |
| 供应商报价（寻货弹窗 / 产品行） | 见 [寻货与分配](寻货与分配.md#六供应商报价批量导入v1057-重构) |

## 七、自动保存与草稿

- **产品明细的增删改与寻货分配**：自动写库，无需手动保存
- **「保存订单」按钮**：仅保存表单元信息（采购方、对接人、项目、交期等）
- **草稿自动保存**：新建/编辑过程存 localStorage，再次进入时提示恢复或放弃

## 八、搜索、筛选与批量删除

- 搜索：单号、采购商、对接人、项目、交期、状态、产品规格、备注（**回车触发**）
- 状态筛选：与搜索可叠加，实时显示「匹配数 / 总数」
- 批量删除：复选框 + 全选 → 工具栏按钮 → 确认弹窗（含结算 / 发票关联检查）
