# 属性与 BOM

## 一、属性管理（六维枚举）

全局枚举字典，供 BOM、签约报价、采购订单选规格时引用。

| 维度 | key | 示例值 |
|------|-----|--------|
| 类型 | `type` | 螺栓、螺母、垫圈、螺钉 |
| 标准 | `standard` | GB/T、DIN、ISO、ANSI |
| 直径 | `diameter` | M6、M8、M10、M12 |
| 硬度 | `hardness` | 4.8、8.8、10.9、12.9 |
| 表面处理 | `surface` | 镀锌(白)、镀锌(彩)、发黑、达克罗 |
| 材质 | `material` | 304、316、碳钢、合金钢 |

操作：

- **新增枚举值**：在对应维度面板输入后回车
- **删除枚举值**：点击值上的 × ；**已被 BOM / 报价 / 订单引用的值禁止删除**（会提示引用次数）
- **批量导入**：支持单维 / 全维批量粘贴
- **导出**：导出全部属性为 CSV

## 二、BOM 管理（SKU 物料清单）

| 字段 | 说明 | 必填 |
|------|------|:---:|
| SKU | 物料唯一编码 | ✅ |
| 名称 | 品名 | ✅ |
| 规格 | 规格描述 | 否 |
| 六维属性 | 类型/标准/直径/硬度/表面处理/材质 | 否 |

### 新建与批量导入

- **单个新建**：点击「+ 新建 BOM」填写
- **批量导入**：复制 Excel 区域 → 粘贴 → 解析预览 → 提交；**按 SKU 去重**，重复行自动跳过

### 与报价 / 订单的关联规则（v1.0.45 起）

> **仅按 SKU 关联**，禁止按规格等其他信息反查。

- 在签约报价或订单产品中选中 BOM，**只回填 SKU 输入框**
- 规格与六维属性是独立填写字段，不从 BOM 复制、不锁定、不被覆盖
- v1.0.55 起恢复「选中 BOM 自动填充六维属性」：**仅填空字段、不锁定、可覆盖**

## 三、数据结构

```javascript
DB.specs = {
  type:     ['螺栓','螺母', ...],
  standard: ['GB/T','DIN', ...],
  diameter: ['M6','M8', ...],
  hardness: ['4.8','8.8', ...],
  surface:  ['镀锌(白)', ...],
  material: ['304','316', ...]
};

DB.bom = [
  { id:'B1', sku:'BOLT-M8-304', name:'M8 304螺栓', spec:'M8×30 304',
    type:'螺栓', standard:'GB/T', diameter:'M8',
    hardness:'8.8', surface:'镀锌(白)', material:'304' }
];
```

## 四、常见问题

**Q：删除枚举值提示被引用怎么办？**
先到 BOM / 报价 / 订单中改为其它值，再删除。系统会在删除时显示引用次数。

**Q：选中 BOM 后属性没填？**
v1.0.55 起会自动填充**空字段**；若字段已有值则保留原值（不覆盖）。如需变更手动修改即可。
