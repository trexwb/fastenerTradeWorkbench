# 数据管理

数据管理页包含：存储状态、本地文件同步、备份与恢复、操作历史、回收站、知识库绑定。

## 一、存储架构

```
┌─────────────────────────────────────────┐
│  浏览器版：IndexedDB（唯一数据库）          │
│           wb_fastener_idb / key          │
│  桌面版：应用数据目录 data.json             │
└──────────────┬──────────────────────────┘
               │  双向同步（时间戳对比）
┌──────────────┴──────────────────────────┐
│      本地 JSON 文件（持久备份）             │
│   File System Access API 句柄存 IDB        │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│    localStorage（仅表单草稿缓存）           │
│  wb_fastener_draft_unit / order / item    │
│  提交后自动清除，不存业务数据                │
└─────────────────────────────────────────┘
```

- `DB` 顶层集合：`units` / `specs` / `bom` / `prices` / `orders` / `settlements` / `invoices` / `aiChats` / `trash` / `aiOps` / `aiWorkflows`
- 启动时 `ensureDBFields()` 补齐缺失字段；导入时 `sanitizeImportedIds()` 清洗非法 id（v1.0.44 起）

## 二、绑定本地文件（强烈推荐）

点击「绑定本地文件」选择（或新建）一个 `.json` 文件，之后每次数据变更会自动写入该文件；文件在别处被修改时，下次启动会提示合并。

> Chrome / Edge 支持（File System Access API）。Safari / Firefox 不支持，会自动隐藏该区块，改用手动导出导入。

## 三、备份提醒与自动快照

- 长时间未备份时顶部提醒
- 按间隔自动快照，保留份数可配
- 备份文件列表支持恢复 / 删除

## 四、导出 / 导入备份

- **导出 JSON**：完整数据（不含回收站与操作历史）
- **导入 JSON**：仅接受 `.json`，校验 + 二次确认；桌面版支持整窗拖放
- 导入后统一走 `ensureDBFields()` 补全字段

## 五、操作历史

记录所有 AI 与手动操作，可**单条 / 整批回滚**。

- AI 操作统计报表（按工具 / 结果统计）
- 筛选器：按类型、时间、来源（AI / 手动）
- 自检与整批回滚

## 六、回收站

- 所有删除（手动 + AI）一律**软删除**进入回收站
- 可恢复 / 彻底删除 / 清空
- **保留 90 天**，超期自动物理清理（关联的未回滚 delete 类 AI 操作标记 `autoPurged`，不可回滚）
- **AI 与回收站完全隔离**：AI 无任何回收站操作能力

## 七、知识库（本地 RAG）

绑定本地目录（md / txt / pdf / docx），自动增量索引 + BM25 检索。详见 [AI 助手](AI助手.md#本地知识库-rag)。

## 八、清空全部数据

危险操作区提供「清空全部数据」，需二次确认。建议先导出 JSON 备份。

## 常见问题

**Q：换电脑怎么迁移数据？**
导出 JSON → 在新环境导入；或把绑定的本地 JSON 文件复制过去重新绑定。

**Q：导入后某些功能报错？**
多为旧备份缺字段。v1.0.44 起导入会统一补齐（`trash` / `aiOps` / `aiChats` / `aiWorkflows` / `bom`）。如仍异常，可再执行一次导入或刷新页面。

**Q：Windows 上导出的 JSON 是空文件？**
v1.0.42 已修复（blob 下载竞态，改为延迟 3 秒释放 URL）。
