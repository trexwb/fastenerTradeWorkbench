# 功能模块总览

侧栏共 9 个顶层入口，其中「对账结算」「发票管理」各含 2 个子项。

| 侧栏入口 | 路由 key | 子项 | 说明 |
|---------|---------|------|------|
| 概览 | `dashboard` | — | 统计卡片 + 今日待办 + 最近订单 |
| 关联单位 | `units` | — | 采购商 / 供应商统一管理 |
| 属性管理 | `specs` | — | 六维属性枚举 |
| BOM 管理 | `bom` | — | SKU 物料清单 |
| 签约报价 | `prices` | — | 供应商 × SKU 报价库 |
| 采购订单 | `orders` | — | 列表 / 详情 / 编辑三态 |
| 对账结算 | `settlements` | `settle-receipt` 收款记录 / `settle-payment` 付款记录 | 应收应付管理 |
| 发票管理 | `invoices` | `inv-issue` 开票记录 / `inv-receive` 收票记录 | 开票收票管理 |
| 数据管理 | `data` | — | 备份 / 同步 / 操作历史 / 回收站 / 知识库 |

另有三个**横切模块**（无独立侧栏入口）：[AI 助手](AI助手.md)、[快捷键与全局搜索](快捷键与全局搜索.md)、Coach 新功能引导。

---

## 1. 概览

- 今日待处理看板：逾期订单标红、今日到期、待确认订单
- 统计卡片：订单总数、待处理、本月签约额、供应商数（键盘可达，`Enter` / 空格激活）
- 最近订单快捷入口（点击进入详情）

## 2. 关联单位

- 供应商 / 采购商统一管理，**一个单位可同时具备两种角色**
- 联系人按角色区分（供应商联系人 ≠ 采购商联系人）
- 支持名称、联系人、电话、角色、评级、账期检索
- 评级（S/A/B/C 或主力/备选/新客）、账期（天数）、备注
- 支持批量粘贴导入 → [关联单位](关联单位.md)

## 3. 属性管理

六个维度枚举：类型 / 标准 / 直径 / 硬度 / 表面处理 / 材质。每个维度可新增 / 删除枚举值（**被引用的枚举值禁止删除**），全局复用。

## 4. BOM 管理

SKU 物料清单（SKU / 名称 / 规格 / 六维属性），支持单个新建与批量粘贴导入（SKU 去重）。签约报价与采购订单**仅通过 SKU 关联 BOM**。

## 5. 签约报价

供应商 × BOM SKU × 单价的报价记录，含六维属性与有效期。按供应商、SKU 维度筛选；同一「供应商 + SKU + 规格 + 属性」组合防重复。采购订单手动录入供应商时自动写入价格库。

## 6. 采购订单

- **多供应商分配制**：一个产品规格可由多个供应商分别供货
- **状态流转**：待确认 → 寻货中 → 报价中 → 签约完成 → 送货中 → 完成
- 按状态分发 Excel 导出；支持订单批量导入
- 送货信息与收货管理**仅「送货中」状态可编辑**

详见 [采购订单](采购订单.md) 与 [寻货与分配](寻货与分配.md)。

## 7. 对账结算

收款 / 付款记录，关联订单自动汇总金额。基于「签约完成 / 送货中 / 完成」状态的订单计算应收应付。详见 [对账结算](对账结算.md)。

## 8. 发票管理

开票 / 收票记录由结算同步生成，可编辑金额 / 日期 / 备注。详见 [发票管理](发票管理.md)。

## 9. 数据管理

IndexedDB / `data.json` 主存储 + 本地 JSON 文件同步 + 自动快照备份 + JSON 导出导入 + 操作历史回滚 + 回收站 + 知识库绑定。详见 [数据管理](数据管理.md)。

## 数据流向总览

```
关联单位 ──┐
           ├──► 签约报价 ──► 采购订单 ──► 对账结算 ──► 发票管理
属性/BOM ──┘        ▲            │
                    │            └──► Excel 导出（按状态分发模板）
                    └────────── 手动录入供应商时自动回填
```

- 订单进入「签约完成」及之后状态才会进入结算聚合
- 发票由结算同步生成；删除结算时可勾选级联删除关联发票
- 所有删除走软删除 → 回收站 → 彻底删除
