# 常见问题

## 运行与环境

**Q：需要安装服务器或联网吗？**
不需要。双击 `dist/index.html` 即可使用，零依赖、离线可用（AI 功能除外）。推荐 Chrome / Edge。

**Q：Safari / Firefox 有什么限制？**
不支持 File System Access API，会自动隐藏「本地文件同步」和「知识库目录绑定」，回退为手动导出导入 JSON。AI 附件在 Safari / Firefox 走上传通道，拖拽与解析可用。

**Q：macOS 桌面版提示「已损坏，无法打开」？**
未公证应用的系统隔离拦截，**并非文件损坏**。终端执行：

```bash
xattr -dr com.apple.quarantine "/Applications/FastenerTradeWorkbench.app"
```

提示 `Operation not permitted` 时加 `sudo `；重新下载安装包后需再执行一次。

## 数据

**Q：数据存在哪里？**
浏览器版存 IndexedDB；桌面版存应用数据目录 `data.json`。另有可选的本地 JSON 文件双向同步做持久备份。表单草稿存 localStorage，提交后清除。

**Q：换电脑怎么迁移？**
导出 JSON → 新环境导入；或复制已绑定的本地 JSON 文件重新绑定。见 [数据管理](数据管理.md)。

**Q：删除的数据能找回吗？**
能。所有删除走软删除进回收站，90 天内可恢复（超期自动物理清理）。

**Q：Windows 导出 JSON 是空文件？**
v1.0.42 已修复（blob 下载竞态）。

## 业务规则

**Q：为什么某张订单没进入结算？**
结算只聚合「签约完成 / 送货中 / 完成」三种状态的订单。

**Q：订单转「异常」后应收应付消失了？**
v1.0.56 起转换时会弹确认窗提示影响的结算金额；转换后不再计入聚合，恢复状态后重新计入。

**Q：为什么送货信息不能编辑？**
v1.0.38 起改为白名单：**仅「送货中」状态可编辑**，其它状态只读（显示 🔒）。

**Q：选中 BOM 后属性没自动填？**
v1.0.55 起恢复自动填充，但**只填空字段**、不锁定、可覆盖。已有值会被保留。

**Q：寻货时价格库匹配出一堆不相关报价？**
v1.0.54 起改为 SKU 优先：行与报价都有 SKU 时必须完全一致；报价无 SKU 时才按属性兜底。

**Q：开始寻货提示要填意向价？**
v1.0.47 起已放开，意向价 0 / 空 / 未填均放行，仅校验 SKU、名称、规格。

## 批量导入

**Q：批量导入支持哪些入口？**
六处：BOM、签约报价、关联单位、采购订单、订单产品明细、供应商报价。统一「复制 Excel → 粘贴 → 解析预览 → 提交」。

**Q：能分多次粘贴吗？**
能。解析成功后文本框自动清空，再次粘贴会**累加**到预览（按各入口主键去重），toast 汇总新增 / 跳过。

**Q：供应商报价导入的列是什么？**
v1.0.57 起：`序号 | SKU（必填）| 数量（千支，必填>0）| 意向价 | 报价（元/千支）| 供应商 | 规格（可选）`。按 SKU 精确匹配订单产品行。示例见 `docs/导入数据Demo.xlsx`。

## AI 助手

**Q：没有 API Key 能用吗？**
能。AI 是可选模块，无 Key / 无网络时核心功能全部可用。

**Q：AI 会直接改我的数据吗？**
不会。写入类工具只生成**提案**，需你逐条确认才执行。查询类工具（query_*）和功能层工具会立即执行但不改数据。

**Q：AI 操作能撤销吗？**
能。每轮 AI 回复下方有「撤销本轮改动」，也可在 [数据管理 → 操作历史](数据管理.md#五操作历史) 回滚。

**Q：AI 能看到回收站吗？**
不能。AI 与回收站完全隔离。

**Q：附件会上传到服务器吗？**
不会。本地直读解析，不上传、不产生临时文件。

## 快捷键

**Q：Windows 上 `Ctrl+K` 没反应？**
当前实现判定的是 `metaKey`（macOS Command），Windows / Linux 下 `Ctrl+K` 不生效。请使用顶栏搜索按钮或鼠标操作。

**Q：输入框里打字母会误触发跳转吗？**
不会。`⌥` 系列在输入框内自动禁用；`⌘K` / `⌘S` 在输入框内仍可用是刻意设计。
