# 关联单位

采购商与供应商的统一管理模块。一个单位**可同时具备两种角色**，联系人按角色区分（供应商联系人 ≠ 采购商联系人）。

## 字段说明

| 字段 | 说明 | 备注 |
|------|------|------|
| 名称 | 单位全称 | 必填，重名不可新建 |
| 角色 | 采购商 / 供应商 | 可多选 |
| 联系人 | 姓名 + 电话 | 按角色分组维护 |
| 评级 | S / A / B / C（或主力 / 备选 / 新客） | 用于筛选 |
| 账期 | 天数 | 参与结算提醒 |
| 备注 | 补充信息 | — |

## 新建单位

1. 点击「+ 新建单位」
2. 填写名称、勾选角色、添加联系人、选择评级与账期
3. 点击保存

**草稿自动保存**：填写过程中数据自动存 localStorage，误关页面后再次点击「新建」会提示恢复或放弃。提交成功后草稿自动清除。

## 批量粘贴导入

入口：列表页「新建」按钮右侧的**分体下拉 → 批量导入**。

- 在 Excel 中按列序整理：`名称（必填）| 角色 | 联系人 | 电话 | 评级 | 账期`
- 复制区域 → 粘贴到文本框 → 「解析」→ 预览 → 提交
- **角色留空默认供应商**
- **重名行自动跳过**（toast 汇总新增 / 跳过条数）

### 导入交互约定（六处导入统一）

- 文本框为空时「解析」按钮禁用
- 解析成功后自动清空文本框
- 可再次粘贴**累加**到预览（按各入口主键去重）

## 搜索与筛选

- 关键词搜索：名称、联系人、电话
- 角色筛选：采购商 / 供应商
- 评级筛选
- 搜索框**回车触发**（不用实时搜索，避免输入法冲突）

## 编辑与删除

- 编辑：点击行操作区「编辑」，在抽屉中修改
- 删除：软删除进入 [回收站](数据管理.md#回收站)，90 天内可恢复
- **被引用检查**：已被订单 / 报价 / 结算引用的单位删除时会提示关联数量

## 与其他模块的关系

```
关联单位
  ├── 采购商 ──► 采购订单.buyerId
  ├── 供应商 ──► 签约报价.unitId / 订单 items[].options[].supplierId
  └── 双角色 ──► 对账结算.unitId / 发票.unitId
```
