# 快捷键与全局搜索

## 一、全局搜索与命令面板（⌘K）

一个输入框聚合**六源检索**：订单 / 客户 / 报价 / BOM / 结算 / 发票，最多 40 条结果，关键字高亮。

| 操作 | 行为 |
|------|------|
| `⌘K` 或点击顶栏搜索按钮 | 打开面板 |
| 输入关键字 | 防抖检索（**不用实时搜索**，避免输入法干扰） |
| `↑` / `↓` | 结果导航 |
| `Enter` | 打开选中条目（订单→详情，结算→结算抽屉，发票→发票抽屉…） |
| `Tab` | 以选中条目为上下文问 AI |
| 无结果 + `Enter` | 直接问 AI |
| `?` 开头 | 强制问 AI |
| `Esc` | 关闭面板（优先级最高） |

## 二、键盘快捷键

> 导航类快捷键统一在 `⌥` 层，避免与浏览器内置快捷键冲突；**输入框内自动禁用 `⌥` 系列**。
> ⚠️ `⌘K` / `⌘S` 判定的是 `metaKey`（macOS Command），**Windows / Linux 下 `Ctrl+K` 当前不生效**。

### 全局导航（非输入状态）

| 快捷键 | 动作 |
|--------|------|
| `⌥ + H` | 概览 |
| `⌥ + O` | 采购订单 |
| `⌥ + U` | 关联单位 |
| `⌥ + P` | 签约报价 |
| `⌥ + B` | BOM 管理 |
| `⌥ + A` | 属性管理 |
| `⌥ + S` | 对账结算 |
| `⌥ + I` | 打开 / 关闭 AI 助手 |
| `⌥ + D` | 数据管理 |

### 全局操作

| 快捷键 | 动作 | 备注 |
|--------|------|------|
| `⌘ + K` | 全局搜索命令面板 | 输入框内也触发 |
| `⌘ + S` | 保存当前抽屉 / 弹窗表单 | 输入框内也触发 |
| `Esc` | 关命令面板 → 关 modal → 关抽屉 → 订单详情回列表 | 优先级依次 |
| `/` | 聚焦当前页面搜索框 | 非输入状态 |
| `?` | 打开快捷键说明 | 非输入状态 |
| `⌥ + ←` / `⌥ + →` | 结算 / 发票页子 Tab 切换 | — |

### 页面动作（上下文相关，非输入状态）

| 快捷键 | 适用页面 | 动作 |
|--------|---------|------|
| `⌥ + ⇧ + N` | 订单列表 / 关联单位 | 新建订单 / 新建单位 |
| `⌥ + ⇧ + E` | 订单详情 / 数据管理 | 编辑当前订单 / 导出 JSON 备份 |
| `⌥ + ⇧ + A` | 订单编辑页 | 添加产品 |
| `⌥ + ⇧ + I` | 数据管理 | 导入 JSON 备份 |
| `⌥ + ⇧ + S` | 数据管理 | 同步文件 |

### 输入框内

| 场景 | 行为 |
|------|------|
| 搜索框 `Enter` | 触发搜索（`isComposing` 防输入法候选误触） |
| AI 输入框 `Enter` | 发送 |
| AI 输入框 `⌘/Ctrl + Enter`、`Shift + Enter` | 换行 |
| combo 下拉 `↑/↓`、`Enter`、`Esc` | 导航 / 选中 / 关闭 |

> 输入框内 `/` 与 `?` 透传给输入框，不触发全局动作。
